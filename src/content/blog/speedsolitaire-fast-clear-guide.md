In [SpeedSolitaire](../../speedsolitaire), time losses usually come from hesitation, not impossible board states.

## Core Loop

Scan tableau priority first, trigger high-information flips early, and keep move cadence steady.  
A smooth sequence of good moves beats occasional perfect moves with long pauses.

## Mistakes To Avoid

1. Cycling the same options repeatedly without advancing board state.
2. Delaying obvious reveal moves while searching for ideal lines.
3. Overvaluing one stack while ignoring global mobility.

## Practice Routine

1. Warmup with a no-pause rule for opening moves.
2. Mid-session run focused on reveal priority.
3. Final run with a "flow check": if stuck, reset scan order immediately.

## Target Milestones

1. Lower average completion time week over week.
2. Increase run completion consistency.
3. Reduce idle decision windows during mid-game.
