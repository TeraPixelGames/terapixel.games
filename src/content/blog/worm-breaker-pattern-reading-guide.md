[Worm Breaker](/worm-breaker) gets easier once you stop reacting late and start reading movement patterns early.

## Core Loop

Identify the active movement pattern, position for the next beat, and keep a conservative escape lane available.  
Late corrections are expensive, so early reads are your best defense.

## Mistakes To Avoid

1. Chasing short-term gains into enclosed space.
2. Mirroring threat movement instead of cutting safer angles.
3. Holding static positions during tempo changes.

## Practice Routine

1. Warmup run with no score greed.
2. Two runs where you call next threat direction before it lands.
3. Final run focused on clean escape setup after each aggressive move.

## Target Milestones

1. Reduce deaths from edge traps.
2. Improve average run length over five sessions.
3. Build a repeatable open-safe-open movement rhythm.
