About this cabinet

About Racer

Built for instant browser play, Racer focuses on readable track layouts, fast restarts, and short competitive runs. Players can practice solo lines or use the live Nakama backend for online race flow as multiplayer features come online.

How to play

Start Fast

Pick a racer, learn the course rhythm, steer cleanly through turns, and use boost windows to improve lap times.

  • Playable Godot web export with direct browser launch
  • Cloud Run Nakama backend for online multiplayer services
  • Short racing sessions built around route learning and replay

Design notes

What to Watch

Racer is designed around toy-track readability: corners, ramps, and boost opportunities should be clear enough to learn quickly while still leaving room for better lines over repeated runs.

Controls

Input Basics

  • Use keyboard movement controls on desktop browsers
  • Use fullscreen mode for the most stable view of the track
  • Keep steering inputs deliberate through corners before accelerating out

Player tips

Improve Your Run

  • Brake or ease off before sharp turns instead of correcting late
  • Learn one track section at a time before chasing full-run speed
  • Use early laps to find boost timing and cleaner racing lines

Player guide

Racer Strategy Notes

Who Racer Is For

Racer fits players who like short, repeatable racing sessions where improvement comes from cleaner turns and better track memory. It is built for quick browser access rather than long setup or downloads.

Learning the Track

Strong runs start with reading the next corner early. Keep the kart stable before entering a turn, then accelerate once the exit is clear instead of overcorrecting midway through the corner.

Online Play

Racer is connected to a live Nakama backend on Google Cloud Run. The web build can use that backend for multiplayer services as supported race modes are exposed to players.

Racer FAQ

Can I play Racer in the browser?

Yes. Racer has a web build that launches directly from Terapixel Games.

Does Racer use online services?

Yes. Racer is wired to a Cloud Run Nakama backend for multiplayer and online race services.
